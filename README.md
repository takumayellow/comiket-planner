# comiket-planner

行きたいサークルの「ブロック記号＋番号」のリストから、**完売リスクと優先度を考えた
最適な巡回順**を計算するツール。テキストでも音声でも入力でき、会場の概略図に立ち寄り順を
重ねて表示する Web UI 付き。

> サークルの実データ（名前↔配置のデータベース）は持ちません。会場の**レイアウト（どのブロック
> 記号がどのホールにあるか）だけ**を事実データとして持ち、あなたが入れた行きたいリストを
> その上で最適化します。データの出典と再配布の可否は [`docs/data-sources.md`](docs/data-sources.md)。

## できること

- **入力**: `西あ36a *1 ごちうさ` のような行を並べるだけ。範囲(`エ2-19`)・列挙(`q06,10,16`)、
  `*1`〜`*5` で優先度、右側にメモ（サークル名）。音声入力も可（サーバに ASR キーがあるとき）。
- **照合**: ブロック記号→ホール→ジャンルを公式のホール別ジャンル配置で解決。
- **巡回最適化**: 到着が遅いほど価値が下がる「完売減衰」つきの巡回（prize-collecting TSP）を、
  優先度・壁サークル・棟間移動コストを考慮して 2-opt で解く。時間予算を切ると、報酬密度の低い
  サークルから自動で落とす。
- **概略図**: 公式地図画像は使わず、事実データの座標モデルから SVG を自前描画して立ち寄り順を可視化。

## 使い方

### CLI

```bash
# 行きたいリストをファイルに書いて
cat wishlist.txt
#   東H07 *2 ホロライブ
#   東D24-37 *2 フブキ
#   西あ36,38 *2 ごちうさ
#   南q06,10,16 *3

python -m comiket_planner.cli wishlist.txt --start 10:30
python -m comiket_planner.cli wishlist.txt --start 10:30 --start-zone east7 --budget 180 --json
```

### Web UI（セルフホスト）

```bash
pip install -e ".[web]"
uvicorn comiket_planner.web:app --reload
# http://127.0.0.1:8000
```

音声入力を使うなら、サーバ側に `GROQ_API_KEY` を設定（`whisper-large-v3` を利用）。
無くてもテキスト入力で全機能が動く。

## 会場レイアウトの作り方（事実データ）

```bash
bash scripts/fetch_official.sh     # 公式の折込地図PDF/ジャンル表を各自の手元に取得（同梱しない）
python scripts/build_layout.py     # そこから読んだ事実だけを data/layout/c108.json に変換
```

`data/official/`（PDF等）と `.local/`（個人の録音・確定リスト・巡回結果）は
**リポジトリに含めません**（`.gitignore` 済み）。

## 仕組み（コア）

| モジュール | 役割 |
|---|---|
| `catalog.py` | 入力テキスト → 構造化された配置(Placement)。範囲・列挙・優先度・ラベルを解釈 |
| `layout.py` | ブロック記号＋番号 → ゾーン内座標。島/壁の幾何モデル、棟内通路距離、棟間移動時間 |
| `router.py` | 完売減衰つき巡回の最適化（貪欲構築 + 2-opt、予算超過時の prize-collecting） |
| `schematic.py` | 事実座標から会場概略図(SVG)を自前描画 |
| `web.py` / `static/` | セルフホスト可能な Web UI + API |

## テスト

```bash
pip install -e ".[dev]"
pytest -q
```

## 公開・SaaS 化について

このリポジトリはそのまま Render / Fly / Vercel 等へ載せられる状態にしてあります。ただし
**一般公開デプロイの前に [`docs/data-sources.md`](docs/data-sources.md) の線引き**（サークルDBを
配信しない・公式地図画像を同梱しない・音声処理のコスト/濫用管理）を必ず確認してください。
現時点の推奨は「**ツールとデータの分離**」＝ツールは公開、個人データは手元(`.local`)。

# データの出典と再配布の可否（公開前に必ず読む）

このリポジトリを**公開**する／**SaaS として提供**する前に、使っているデータが再配布・
サービス提供して良いものかを切り分ける。結論を先に書く:

- ✅ **このツール本体（パーサ・座標モデル・巡回最適化）は公開可**。
- ✅ **`data/layout/c108.json` の「ブロック記号 → ホール」対応は事実データで公開可**（下記参照）。
- ❌ **折込地図PDF・カタログ画像は同梱/配信不可**（個人利用ダウンロード物、再配布禁止）。
- ❌ **サークル名・サークル配置データベース（Webカタログ由来）は同梱/配信不可**。
- ⚠ **ライブ公開 SaaS でサークルデータをホストするのは保留**（下記「SaaS の線引き」）。

## 1. 折込地図PDF（`data/official/C108Map_*.pdf`）

- 出典: コミックマーケット準備会 公式サイトの折込地図（2026-07-22公開）。
- ファイルに **print code の有効期限（2026-08-21 23:59）** が入っている＝**個人がその場で
  印刷して使うための配布物**。二次配布を前提にしていない。
- → **リポジトリに含めない**（`.gitignore` で `data/official/` を除外済み）。各自が
  `scripts/fetch_official.sh` の URL から自分でダウンロードする方式にする。
- このツールは PDF画像そのものは持たず、**そこから読み取った「事実」（島の並び順・
  番号の回り方）だけ**を座標モデルに変換して保持する。

## 2. ホール別ジャンル配置（`data/layout/c108.json` の genre_*）

- 出典: 公式「ジャンルコード一覧 / ホール別ジャンル配置」ページ。
- 「東1 = ア01〜39 + イ〜ス」「西2 = あ〜ち」等の **ブロック記号とホール/ジャンルの対応は
  事実情報**。事実そのものに著作権は及ばない（編集著作物としての表全体の丸写しは避け、
  必要な対応関係だけを自前のデータ構造に再構成している）。
- → 公開可。ただし公式表の体裁をそのままコピーはしない。

## 3. サークル名・配置データ（Webカタログ / サークルカット）

- サークル名・スペース番号・サークルカットは **Webカタログ等の利用規約で再配布が制限**される。
- → **このリポジトリにはサークルの実データベースを一切置かない**。ユーザーが自分の
  「行きたいリスト」を入力する（＝自分で持っている情報）だけを処理する設計にする。
- 個人の確定リスト（録音を照合したもの）は `.local/`（git対象外）に置く。

## 4. SaaS の線引き（なぜライブ公開を保留したか）

ユーザー入力（テキスト/音声）→ 照合 → リスト＆最短経路、というサービス自体は、
**「ユーザーが自分の行きたい場所を入れる」→「事実の会場レイアウト上で経路計算する」**
だけなら、著作物である**サークルDBを配信しない**ので比較的クリーン。

ただしライブで一般公開するには次が未解決なので、**公開デプロイ＆宣伝は本人の GO 待ち**とする:

1. **サークルDBを持たない照合の限界**: 「ごちうさ→西あ36」のような *名前→場所* の照合には
   結局どこかにサークル配置データが要る。これを持てば再配布に触れる。持たなければ照合は
   「ユーザーがブロック記号＋番号を入力する」前提に留まる（＝本ツールの現状）。
2. **音声処理のコストと悪用**: サーバ側 ASR は API キー＝課金とレート制限を伴い、公開すると
   コスト/濫用の管理が要る。
3. **運用主体の責任**: 「コミケの」を冠する外向きサービスは、準備会との関係・問い合わせ対応が要る。

→ **現時点の適切な形 = ツール／データの分離**:
- **公開リポジトリ**: ツール本体 + 事実レイアウト + セルフホスト可能な Web UI。
- **非公開（`.local`）**: 録音・個人の確定リスト・個人の巡回結果・DLした公式PDF。
- Web UI はローカル/セルフホストで完全動作する。**一般公開デプロイは、上の1〜3を潰して
  ユーザーが「出して良い」と判断してから**（このリポジトリはそのまま Render/Fly/Vercel 等へ
  乗せられる状態にしてある）。
